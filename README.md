# Shaik Roshini · Portfolio

Animated scroll-story portfolio for Shaik Roshini, Visual & Brand Designer (Bangalore).

- Single static page: `index.html` (images are embedded, GSAP loads from cdnjs)
- Light and dark themes, follows the visitor's system setting with a manual toggle
- Chapters: process scene, services, selected work (Belvaa, Roaha, WCPC book, Royal Sabah, Hacker Academy), journey, toolkit, contact

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

## Deploy

Works as-is on Netlify, Vercel or GitHub Pages (Settings → Pages → deploy from `main`, root folder).
